How to read Defense IQ

Expected pick estimates which class a player will spend the most recorded defensive-class time on. Each earlier match contributes one observation, favoring recent games with a 180-day half-life. Same-map history is blended with overall habits, using five prior observations; overall habits have one smoothing observation per class. These estimates have not been calibrated against future games.

Actual choice shows the time split between HWGuy, Demoman, Soldier, and Engineer. Percentages exclude all other classes. A tie for most time is labeled mixed and excluded from prediction labels and class result buckets. Players without recorded defensive time remain unscored.

Historical results are team wins, losses, and ties on this map when that class had the most defensive time. Win percentage excludes ties and unknown results. Match review uses only earlier history for both predictions and results. Mixed matches are excluded from class results.

Only completed 4v4 pickups and unambiguous player identities are included. Small samples can swing sharply. These records describe habits and team outcomes; they do not establish the best class or the cause of a loss. Ping and Elo are not model inputs.
