# Parent Guide

Prepare a new weekly mission in under two minutes:

1. Open **Parent Zone** from the home screen.
2. Choose **New List**, enter a list name, and paste the week's words separated by new lines (or commas).
3. Save the list. Duplicate entries are removed automatically and the new list becomes active immediately.
4. Add optional sentence writing later by using Practice Mode's sentence button; custom words receive a safe generic sentence automatically.
5. Use **Back Up Data** whenever you want a portable copy. Browser storage is local to this device and can be cleared by browser settings.

The dashboard distinguishes new, learning, missed, and mastered words. A word is mastered only after at least three correct attempts including two first-attempt successes, so one lucky answer does not hide a practice need.
